# G. Manohar - AI/ML Leadership Portfolio

Personal portfolio for G. Manohar, a strategic data science and AI leader focused on Agentic AI, enterprise AI delivery, computer vision, and MLOps.

Live site: [manohargov.github.io/Portfolio](https://manohargov.github.io/Portfolio/)

## Portfolio content

- Executive profile and contact links
- AI/ML, cloud, engineering, and delivery skills
- Career history from manufacturing engineering through global AI program leadership
- Selected Agentic AI, GenAI, computer vision, and optimization projects
- Professional recognition, education, and training
- Downloadable CV

## Local development

Prerequisites:

- Hugo Extended 0.162.0
- Go 1.23 or newer
- Node.js 22
- pnpm 10.14.0

```bash
pnpm install
pnpm run dev
```

Create a production build with:

```bash
pnpm run build
```

The site is built with HugoBlox and deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.
